# Homebrew Neon

A dark retro terminal theme using `#11FF00` as the primary accent color.

## Palette

| Role | Color |
|---|---|
| Background | `#050805` |
| Foreground | `#E7FFE4` |
| Cursor / Accent | `#11FF00` |
| Selection background | `#123D10` |
| Selection foreground | `#E7FFE4` |

## ANSI Colors

| Color | Normal | Bright |
|---|---:|---:|
| Black | `#0B120B` | `#4B684B` |
| Red | `#FF4D4D` | `#FF8080` |
| Green | `#11FF00` | `#72FF66` |
| Yellow | `#D8FF3E` | `#EAFF8A` |
| Blue | `#4DA6FF` | `#82C2FF` |
| Magenta | `#FF5CFF` | `#FF91FF` |
| Cyan | `#44FFD2` | `#8AFFE5` |
| White | `#D9FFD6` | `#FFFFFF` |

## Included formats

- `windows-terminal-homebrew-neon.json`
- `iterm2-homebrew-neon.itermcolors`
- `kitty-homebrew-neon.conf`
- `alacritty-homebrew-neon.toml`
- `wezterm-homebrew-neon.lua`
- `ghostty-homebrew-neon`
